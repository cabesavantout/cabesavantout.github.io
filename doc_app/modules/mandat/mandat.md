# 🏛️ Module Mandat — Version améliorée (structure cible)

## 🧠 Objectif global

Le module **Mandat** permet de comprendre, analyser et exploiter politiquement l’ensemble du mandat.

👉 Il doit répondre à une logique claire :

```
Promesses → Décisions → Réalisations
```

👉 Tout le reste (Budget, Évaluation, Chronologie, Sujets) vient enrichir cette lecture.

---

## 🧩 Structure globale

### 1. Vue Mandat (cockpit)

#### Objectif

Donner une vision immédiate et actionnable.

#### Contenu

- Top promesses critiques
- Sujets sensibles
- Réalisations clés
- Incohérences majeures
- Actions prioritaires

👉 Cette vue doit permettre de comprendre le mandat en **30 secondes**.

---

### 2. Promesses (cœur du module)

👉 Point d’entrée principal

- engagements
- statuts
- preuves
- analyse politique

🔗 Liens obligatoires :

- Décisions
- Réalisations
- Budget
- Territoire

---

### 3. Décisions (mécanisme)

👉 Chaînon central

- actes politiques
- arbitrages
- déclenchement des réalisations

🔗 Doit toujours répondre à :

- quelle promesse ?
- quelle conséquence ?

---

### 4. Réalisations (preuve)

👉 Base factuelle

- ce qui est réellement fait
- niveau d’impact
- niveau de preuve

🔗 Toujours relié à :

- promesse
- décision
- budget

---

### 5. Sujets / Thématiques (structure)

👉 Organisation politique du mandat

- regroupement transversal
- lecture par thème

🔗 Agrège :

- promesses
- décisions
- réalisations

---

### 6. Chronologie (dynamique)

👉 Lecture temporelle

- événements
- séquences politiques

---

### 7. Budget (transversal)

⚠️ IMPORTANT :
Le budget n’est pas isolé.

👉 Il doit apparaître dans :

- Promesses
- Décisions
- Réalisations
- Sujets

👉 Le sous-module Budget devient une **lecture financière globale**.

---

### 8. Évaluation (transversal + synthèse)

⚠️ IMPORTANT :
L’évaluation existe à deux niveaux :

#### Niveau local

- dans Promesses
- dans Sujets
- dans Réalisations

#### Niveau global

- synthèse du mandat

👉 Ce module agrège les évaluations existantes.

---

## 🧠 Logique clé du module

```
Promesse
   ↓
Décision
   ↓
Réalisation
```

👉 + enrichissement :

- Budget
- Territoire
- Terrain

👉 + lecture :

- Sujets
- Chronologie
- Évaluation

---

## 🧠 Objectif produit

Le module doit permettre de :

- comprendre rapidement le mandat
- identifier les incohérences
- préparer des arguments
- prioriser les actions

👉 Ce n’est pas un outil de stockage
👉 C’est un outil de **lecture politique et stratégique**

---

## 🏁 Conclusion

Le module Mandat doit devenir :

👉 un cockpit politique
👉 un outil d’analyse structuré
👉 un moteur de décision

C’est la **colonne vertébrale de toute l’application**.
