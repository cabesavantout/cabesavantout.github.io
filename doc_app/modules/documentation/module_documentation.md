# 📚 Module Documentation

## 🧠 Objectif

Le module Documentation est la **mémoire structurée et vérifiable** de l’application.

Il permet de :
- centraliser toutes les sources
- relier les documents aux sujets, promesses et zones
- garantir la traçabilité des informations

👉 afin de disposer de **preuves solides et exploitables**.

---

## ❓ Question clé

👉 Quelles sources fiables appuient mes analyses, décisions et messages ?

---

## 🧩 Rôle dans l’application

- Référentiel documentaire
- Base de preuve
- Support du Mandat, de la Campagne et de la Communication

Le module Documentation **n’est pas** :
- un simple stockage de fichiers

👉 Il **structure et relie les informations**.
