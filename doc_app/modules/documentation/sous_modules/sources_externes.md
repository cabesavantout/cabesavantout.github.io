# 🧩 Sous-module Documentation — Sources externes

## 🧠 Objectif

Le sous-module **Sources externes** regroupe **les éléments non produits par la mairie ou la presse**.

Il sert à :

- archiver les tracts et communications de l'opposition
- stocker les rapports d'audits (Chambre Régionale des Comptes)
- conserver les données macro-économiques (études Insee PDF, arrêtés préfectoraux, rapports d'agglomération)

---

## ❓ Question clé

👉 Quels documents venant de l'extérieur peuvent être exploités contre ou pour le bilan de la majorité ?

---

## 🧩 Rôle dans le module Documentation

- C'est le module "Veille Stratégique".

Alimente :

- **Campagne (Risques & Vigilance)** : Les tracts adverses permettent d'analyser l'angle d'attaque des opposants.
- **Mandat (Budget / Évaluation)** : Le rapport de la Cour des Comptes est la meilleure source pour attaquer une gestion financière.

---

## 🎯 Finalité métier

Permettre de répondre à :

1. Sur quel thème l'autre liste d'opposition a-t-elle axé son dernier tract ?
2. Qu'a préconisé l'audit de la Chambre Régionale des Comptes sur l'endettement de la commune ?

---

## 🧱 Structure recommandée

### Catégorisation

- Opposition politique.
- Rapports institutionnels (Cour des comptes, Agglomération).
- Veille thématique.

---

## 🧠 Données attendues

- `document_type = 'source_externe'`
- Ajout systématique de tags pour pouvoir retrouver le document lors d'une recherche thématique.

---

## 🏁 Conclusion

Le sous-module **Sources externes** est :
👉 le pôle de renseignement concurrentiel et institutionnel
